4.12
If we have not received the ack, we need to send the message again until we receive the ack.
So every time we send a message, we add seqnum in a list and when we receive the ack, we remove the seqnum from the list.
Also, we sleep(2) for waiting 2 seconds to check acks again.

4.20
PostgreSQL handles identifiers (like table and column names) in a case-sensitive manner when they are quoted. We have some 
column name created with quotes and in mixed case (e.g., "upsUsername"). So we need to reference it with quotes in SQL.
